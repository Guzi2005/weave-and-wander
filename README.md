# Weave & Wander: 3D Doll Study

独立的 Godot 4.7.1 对照工程。纸偶版仍在 `../dollhouse`，没有被覆盖；封存包在 `../snapshots/paper-puppet-v1-20261010.zip`。

## 打开

用 Godot 4.7.1 打开本目录的 `project.godot` 并运行。默认全屏，适配 PC 和平板横屏，F11 切换窗口。

- 店铺保留员工与顾客的自主活动、拖拽部署、暂停、调速和换装。
- 右上人偶图标进入近景转台，可旋转、走动和替换发型、衣服、配色。
- 从转台返回店铺会重新开始演示；当前不保存经营进度。
- 员工卡保留扁平插画头像，场景角色为真正的立体网格。
- 滚轮向前拉近进入店内剖视，向后拉远看街景；平板支持双指捏合。场景缩放不影响暂停和经营速度，屋顶掀起只在近景启用。
- 空白处左键或中键拖动平移，右键拖动转动视角；平板单指拖动空白处、双指平移与捏合、双指扭转调整水平视角。员工拖动仍用于部署，UI 不会带动镜头。Home 恢复默认位置与角度；房间导航或员工定位恢复居中，缩放保留手动偏移。

## 锁定的造型方向

2026-10-12：人物身形暂定，不再扩展复杂肩袖曲面；本轮只修正侧面头型与五官贴合。前店完成后，按用户新要求扩展为左右相连的三个房间。

首要视觉基准是用户反复选定的 `captures/dolls_3d_turntable.gif`，封存副本为 `../snapshots/doll-silhouette-reference-20261010.gif`。该 GIF 不覆盖、不重生成。原作侧面截图只作为补充参考。

用户已明确停止复杂曲面路线：采用简单身筒、内藏袖根、向下展开的锥形宽袖和独立服装部件。观感与可复用性优先，不再以连续肩袖曲面作为默认目标。当前实现是按参考重建，不是找回了该 GIF 对应的旧源代码；新截图仍需用户认可，不能自动替换视觉基准。

- 成人约四头身，窄上身、贴身垂臂与向下展开的衣摆形成圆锥形；不显示外凸球形肩关节。
- 豆眼与简单圆球鼻子，不添加复杂鼻梁。
- 头部前后厚度接近高度，保留原正面宽度；五官按同一椭球表面定位，鼻根嵌入脸部约 0.04 单位。头发同步增加前后体积，头与鼻子继续共享头骨蒙皮。近景见 `captures/rounded_head_profiles.png`。
- 头发是独立立体发壳，衣物是有厚度的独立网格，宽袖口有内衬。
- 鞋底为平面，行走时控制足部高度和旋转。
- 2026-10-15 视觉基准确定为“人物用 P1，场景用 P2”：整个人物（皮肤、头发、衣物、帽子、随身邮包）恢复最扁平的印刷色块，使用 `doll_volume.gdshader` 的弱明暗分色（亮度范围 0.94–1.0、`tone_steps=2`）与微量纸面颗粒（`tooth=0.075`），无描边。取消之前仅衣物加强、脸与头发保留多级明暗的覆盖逻辑。建筑、家具、陈列衣物、街道、自行车等继续使用 P2 原有的实时光照、投影与纸面质感；不改变全屏后处理。角色仍有三维网格、完整蒙皮和落地投影，身形、动作与镜头不变。
- 紫色兜帽长袍仅用于轮廓对照，不作为本游戏的文化服饰内容。

## 骨骼与衣物

`scripts/doll_rig.gd` 生成真正的 `Skeleton3D`、`Skin` 和每顶点最多四项权重。共 20 根骨骼，包含躯干、头、双臂、手、双腿、脚及四根衣摆辅助骨骼。

默认 `components/simple_garment.gd` 生成身筒和左右袖筒三个简单网格部分，袖根藏在身筒中。三部分并入同一渲染网格，但不宣称是焊接的连续曲面。肩骨转轴内藏，袖根权重过渡到躯干；默认垂臂姿态直接写入造型，不再用反向肩肘旋转收窄模型。

连续曲面版本保留为实验组件 `components/garment_shell.gd`，默认模板与运行时均不调用它的曲面生成方法。完整实验快照在 `../snapshots/continuous-shoulder-experiment-20261011.zip`。

纽扣为带平底的半椭球网格，按钮行节点控制数量、间距和尺寸，并贴合上衣表面。短褂前襟从身筒网格生成。可复用模板与限制见 `components/README.md`。

衣物叠层优先继承内层蒙皮权重，保留必要间距，不靠加厚硬壳修补：短褂和前襟跟随内搭，围裙跟随内搭与裙面，口袋跟随围裙。`scripts/layer_skin_binding.gd` 在生成时传递权重，运行时仍用共享骨架的 GPU 蒙皮；不是逐帧布料碰撞。

长裙和围裙使用腰部与衣摆骨骼，不直接跟随单条腿扭曲。长衣遮住的腿部网格不生成，鞋子保留；行走时衣摆适度展开，足部姿态补偿使鞋底保持水平。这是针对现有服装的蒙皮和遮挡规则，不是通用布料碰撞模拟。

`volume_doll.gd` 负责造型与模块，`paper_doll.gd` 仅复用既有角色状态接口和插画头像生成，不在场景中保留纸偶插柄。

## 可编辑资产

`models/` 包含四个人偶的 `.tscn` 与 `.glb`：围裙、长裙、短褂、兜帽长袍。

- `.tscn` 保留 Godot 材质、独立网格、骨骼和 AnimationPlayer。
- `.glb` 可导入 Blender，包含同一骨架、蒙皮与 `idle`、`walk`、`sewing` 动画；导出时使用标准纯色材质，不包含 Godot 专用印刷 Shader。
- 可运行 `tests/export_models.gd` 更新资产。导出器会重新导入 GLB 并播放行走动画，检查骨骼和动作没有丢失。

技术 API 依据：[Godot Skeleton3D](https://docs.godotengine.org/en/stable/classes/class_skeleton3d.html)、[Godot GLTFDocument](https://docs.godotengine.org/en/stable/classes/class_gltfdocument.html)。

## 逐件库存与顾客决策

**2026-10-17 当前版本**：下述 10 月 15 日整套款式记录已由单件系统取代。目录包含连衣裙、围裙、马甲、衬衣、长裤、半裙及贝雷帽/渔夫帽/宽檐帽，共九种模板。开店时衣架 6 件、帽架 3 件、库房 3 件。套装来源以 `collection_id` 关联，但单件独立预留、拿取、试穿、判断、退回与结算。顾客一次可选择 1–3 件预算内、不冲突的单品，先逐件拿取再去试衣；照镜后可以只留其中一部分，其余换下送回衣篓。柜台按单件记录交易，销售计数是件数。

`garment_definition.gd` 定义四类穿戴槽（上装、下装、外搭、头饰）；`catalog_doll.gd` 复用原有蒙皮模板并生成三种帽子。`garment_item.gd` 只保留该单件所属网格，挂起、手持、穿戴、退回时始终使用原网格与原物件 ID，不用缩放伪装状态。手持目前使用原尺寸扇形展开，不是折衣模拟。试戴帽子不换掉衣服，试穿马甲不隐藏衬衣和裤子。身体头部、手和鞋保持原骨架，衣物复制其骨骼姿态；帽子绑定头骨。

**衣架与服装的关系**：`components/garment_hanger.gd` 是家具拥有的独立衣架。肩式架最多两件兼容内搭/外搭，双木夹板一字裤架和肩带架目前一件；帽架最多三顶同帽型。`ShopInventory.slots` 每格存放单件数组；`display_item(item,index)` 检查类型、容量和占用规则，`free_slot(item)` 优先空位，其次兼容叠放。每件有独立挂点，不整体缩放；顾客可只取外搭或连同内搭一起取走，未选中的物件仍在原架。全部取尽才为空架。自动补货同样遵守这些规则。当前没有玩家陈列编辑 UI、解夹动画或布料物理。

**对象生命周期与服务**：衣物节点始终归库存所有，顾客只持有临时 `RemoteTransform3D` 代理。顾客被销毁不会连带删除衣物；正常离店主动交接，意外失去持有人由库存回收。`service_queue.gd` 为试衣间/柜台提供 FIFO 和四个独占等待点，跟随家具变换；不是全局人群避让系统。结账只在员工实际到柜台工作时推进，中途离岗重置服务时间，库存交易入口也验证员工在岗。

**衣物形态与线轴**：`garment_forms.gd` 为同一网格生成挂起、侧折、对折、叠好形态，仍使用原商品和材质，不是缩小替代模型；当前形态切换没有过渡动画。`components/thread_spool.gd` 提供真实连续绕线、圆边端盘和中空芯轴，场景/缝纫机共用缓存几何。

`tests/shop_service_test.gd` 覆盖同架单取/多取、叠帽容量、持有人销毁、试衣等待位置、无人收银与服务中断。实机截图：`captures/stacked_hangers_1600x900.png`、`captures/wood_trouser_clamp_1600x900.png`、`captures/wound_thread_spools_1600x900.png`、`captures/fitting_queue_spaced_1600x900.png`。

`tests/single_piece_test.gd` 验证挂点/朝向一致、夹架类型、空衣架、单件取还、暂停搬动家具，以及九种服饰穿戴和四件混搭。阶段截图：`captures/hangers_stocked_1280x800.png`、`captures/hangers_one_piece_taken_1280x800.png`。

针对“头飞了”：旧截图测试在暂停时移动人物，但衣物只随经营更新，导致衣物留在原地。先前仅补截图同步不够；现已在衣物运行时和视图更新中补上附件同步，与经营暂停分离。`tests/single_piece_test.gd` 直接在暂停时改变人物位置、旋转和头骨姿态，不主动调用衣物同步，验证九种单品及四件混搭仍跟随角色。`reflection_depth_preview.gd` 也已移除测试专用补丁。

帽架现在位于原前店缝纫机的位置；原先它实际在前店左后方，被成衣架遮住，并非独立的后排经营设施。缝纫台移入左侧工坊，寻路、操作点和生产岗位随之调整，总计 13 个设施。`components/sewing_machine.gd` 提供带真实机身开口、针杆、压脚、送布齿、手轮、调节盘、线轴走线的程序化机器；脚踏和电线随桌面组件生成。前店的帽饰岗位用于补货，真正缝制只在工坊的缝制台完成。

本轮预览：`captures/single_piece_outfit_*`、`single_piece_paused_moved_*`、`single_piece_displays_*`、`single_piece_shop_*`、`sewing_machine_workshop_*`。这是通用基础款验证，民族服饰出处研究、文创商品、策略树、采风、采购、DIY 与编辑器管线见 `../../Docs/DEVELOPMENT_ROADMAP.md` 的后续主线，未宣称实装。

2026-10-15：`scripts/shop_inventory.gd` 管理每件服饰实物，开店时衣架 5 件、库房 3 件。每件记录款式（长裙、围裙装、短褂）、配色、价格、位置（衣架槽位、库房、衣篓、拿在手上、穿在身上、已售出）和当前顾客。衣架上挂的是人偶同款的立体服装网格；被取走后槽位真实空出，试穿过的衣服搭在衣篓上，售出后随顾客离店。原纸片画衣和衣篓里的假叠衣已移除，只保留衣架。

`scripts/customer_profile.gd` 生成三种顾客：本地居民、游客、爱好者。每人有想要的款式（硬要求）、喜欢的配色（爱好者还有一种不喜欢的配色）、预算和购买门槛。`scripts/customer_behavior.gd` 的行为树：进店浏览，只从衣架上实际挂着的衣服里按款式、配色和价格挑选；没有合适款式或都超预算就说明理由离开。挑中后拿着衣服在隔间外排队，轮到才进入，关帘换上，出来照镜；合身程度要到镜前才知道。照镜后有三种结果：买下并穿着走；换回原衣服再买；或说出理由（颜色不喜欢、不太合身、有点贵）、放回衣篓，最多再挑一件。柜台没有店员在岗时保持等待，实际到岗后才服务；中途离岗不会继续倒计时付款。

doll.set_expression("happy", 0.35)
