# 换对话交接：Weave&Wander 针脚与远方

核对日期：2026-11-05。此文件记录需求、现状与未闭环事项，不代表所有功能已验收。本次只做交接审计，未重新运行全部测试。工作目录为 `D:\GodotProjects\weave-and-wander\prototypes\dollhouse-3d`。

## 不得弄错的方向与偏好

- 游戏本体名为 Weave&Wander 针脚与远方；百工坊是资产编辑器系列。
- 经营核心是开罗式宏观策略，结合细致制作步骤及定制的自动演绎。
- 材料实体、库存、成衣必须同源：颜色、纹样、材质、幅宽、厚度、剩余量影响制作与外观。不能只给蓝色围裙换色演示。
- 收纳参考用户提供的密集布料/毛线商店：密集的是实物，不是空插杆。允许靠放、侧放、倾斜、堆叠；美观不能靠虚构库存填满。
- 图书馆式布料是连续布包绕纸板，侧面可见多层与软转折，纸板可在上下端露出；不是两块布夹板。厚度随布厚和用量变化。
- NPC 要实际取放、搬运、展开、制作、归还与整理，有接触和姿态，避免漂浮、穿模、突然断接。
- 身体以原先统一体型和用户参考为准。应加宽手臂，不是缩窄手掌；颈肩自然过渡；imagegen 三视图不能改变体型。
- 小花为独立小物，分批生产并能选不同面料；纽扣暂时维持原色。
- UI 不要白底框套框、黑色线描简笔画。保留布料填充展示及纹样比例。标签省掉颜色和“材质/纹样/版型”等前缀。
- 字体附件为江城圆体 500W/400W，用户确认“都能用”；当前使用 500W。
- 经常给真实运行截图；不能用生成图代替实装证据。
