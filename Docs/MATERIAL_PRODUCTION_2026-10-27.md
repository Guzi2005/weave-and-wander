# 耗材实体与围裙制作，2026-10-27

本次实现接入原有 Godot 工坊、员工安排、商品库存和顾客购买流程。入口为左上角「材料与制作」。首件示范围裙使用湖蓝布料，完成后可选择其他布料和缝线；「缺货时自动补制」控制后续自动安排。

## 收纳外观与实物库存

- 新材料柜含 17 本布册、4 卷布、20 轴缝线、18 团毛线，共 59 个独立库存实体。扩展的开局库存由 `scripts/material_catalog.gd` 定义；数量没有通过纯装饰复制。
- 布册按实际厚度紧排，排尾斜靠；另一格混合竖放与横叠。线轴紧邻排列，毛线以三团一组堆放在六个小格，支撑结构退到后方。成衣接收桌位于柜旁，不遮挡材料。
- 布册厚度随剩余米数线性减少；卷布/线轴按卷绕截面积缩小，保持芯轴；毛线体积随数量变化。当前采用可读性优先的尺寸标定，不是生产级物理绕卷或布料模拟。
- 每个实体持有独立材料 ID、颜色、花纹、材质、剩余量和位置记录。布册/布卷、裁片、成衣共享颜色和纹样规则；穿着/折叠保持同一商品身份。

## 已接通的制作过程

围裙工单选择一批布、一轴线：预约材料 → 取布 → 双手搬运 → 裁剪台展开 → 裁剪 → 余布归架 → 拿取和安装线轴 → 搬运裁片 → 缝制 → 成衣放到侧桌 → 送回空托盘 → 剩线归架。

布料在裁剪成功时扣除，缝线随缝制进度扣除，估算区分成衣净用量、可用余料、损耗和条纹/格纹对花余量。余料出现在裁剪台下。重复结算不会复制商品或重复扣料。生产状态暂停不前进；换人时保留进度，搬运中先放下周转物，再由接班员工取回继续。成衣折叠厚度按薄围裙调整。

## 验证入口

使用 Godot 4.7.1，在项目根目录执行 `--headless --path . --script res://tests/<文件名>`：

- `material_ledger_test.gd`：预约、扣除、守恒、取消和重复调用。
- `material_package_test.gd`：五种包装形态共 280 项检查。
- `material_storage_test.gd`：59 个实体与账目对应、布册无相交、数量缩小、移动柜体、开局库存幂等及刚好够用的缝线。
- `material_production_test.gd`：完整围裙制作，验证数量、来源、手部距离及归位。可加 `-- --fabric=cream_roll` 或 `-- --fabric=rose_check`。
- `material_interruption_test.gd`：18 个制作节点的换人/中断。
- 既有 `inventory_flow_test.gd`、`staff_stamina_test.gd`、`dynamic_navigation_test.gd`、`checkout_packing_test.gd`：整店库存、销售、员工与导航回归。

GPU 截图需去掉 `--headless`：`material_flow_capture.gd` 生成柜体和制作面板；`material_production_test.gd -- --material-capture --test-window=1600x1000 --fabric=rose_check` 记录取布、展开、缝制和完成状态。图片保存到 `captures/material_*.png`。

## 布料绕板结构修正

根据新增折布/卷板参考，将布册由方块外壳改为连续圆角包裹网格。布料绕过纸板前后两条窄边，板边仅在上下端露出；两端有卷绕层线，宽面保留布尾折口。数量变化保持纸板尺寸不变，只改变布层厚度；用空后留下空板。竖排、斜靠、横叠与搬运均使用这一个模型。

`wrapped_fabric_test.gd` 通过实际三角形射线检查满量/半量/低余量的正面及左右面遮蔽关系，验证空板、共享库存、顶点/法线有效性，共 39 项。`wrapped_fabric_capture.gd` 使用实际组件生成 `captures/material_wrapped_detail.png`（左到右满量、半量、空板）。`material_production_test.gd -- --move-stations` 验证生产途中移动裁剪台和材料柜后继续操作，工坊柜体已前移以保留染色台站位。
