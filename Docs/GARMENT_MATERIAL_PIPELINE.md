# Weave&Wander 针脚与远方：布料到成衣

在「材料与制作」中选择款式、库存中的布料和缝线，再安排员工。支持现有六种服装模板：连衣裙、围裙、马甲、衬衣、长裤、半裙。布料可以是素色、格纹或条纹；颜色与棉、亚麻等材质来自具体库存批次。

订单建立时固定款式与材料快照。员工沿用取布、展开、裁剪、收回剩布、取线、缝制、折叠、成衣入库和归还线轴的实体流程。切换后续制作选项不会修改已开工的衣服。

成衣沿用同一个物品实例进行折叠、上架、携带、试穿和购买，材料快照不因展示状态改变。保留布料批次、纹样标识、版本、来源、用线与估算成本，以供后续资料关联。

各款式使用不同的布料和缝线估算；布幅影响取布长度，条纹与格纹计入对纹余量。扣料分别发生在裁剪和缝制阶段，重复完成订单不会重复生成衣服。

当前边界：配方是游戏用耗材估算，不是二维排料算法；裁片搬运仍采用简化的叠片表现，不表示每款服装已有真实纸样。六款使用游戏现有服装模型，未新增民族服饰版型。毛线编织、刺绣及帽子制作不属于这条裁剪缝纫管线。

胸花作为独立小物制作：在款式下拉框选择「小物 · 胸花」，自行选择库存布料和缝线。衣服本体订单不再附赠胸花。胸花有自己的订单、材料扣除及来源，可以单独存放，或在制作时指定成衣；已入库胸花也可通过面板装到空闲的连衣裙、马甲或衬衣。若指定成衣已被顾客拿走，胸花保留在小物库存。安装目前是库存组合操作，尚无独立缝花手势。纽扣保留模型原色，不参与整件布料染色。

验证入口：`tests/garment_recipe_test.gd`（配方与库存），`tests/material_production_test.gd -- --fabric=rose_check --style=0`（实际员工生产），`tests/made_garment_lifecycle_test.gd`（成衣展示与试穿），`tests/garment_material_capture.gd`（实际游戏模型与布料对照截图）。
