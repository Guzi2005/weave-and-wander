# 百工坊桌面图标选稿

当前选稿：`workshop-ethnic-16.png`，01—16 共 16 方案，待用户选择后单独制作正式图标和 Windows ICO。

生成方式：内置 imagegen。参考为本项目的实际截图 `captures/startup_normal.png`、`captures/material_complete.png`。

本轮提示词核心：以正在制作民族服饰的工坊为主体；中心裁剪台或缝纫台、密集布料柜、悬挂服装、百褶裙和几何织带共同构成清晰小图标。遵循实际游戏的低多边形纸艺微缩、哑光纸板、青绿色家具与屋顶、暖白墙面、低饱和粉红及赭黄色。避免人物肖像占满图标、普通手工符号、写实布料与亮面玩具质感。4×4 排列，图外编号 01—16。

服饰和装饰纹样为概念生成示意，尚未对应经考证的具体地区服饰样本。正式图标选定后应进一步核对轮廓与纹样来源。该选稿尚未替换正式游戏图标；桌面开发入口暂用 Godot 可执行文件的默认图标。
